# Лабораторная работа 2: Класс «Время» на C++

## Содержимое проекта:
- Time.h / Time.cpp - класс времени
- Flight.h / Flight.cpp - класс рейса и расписания
- flights.txt - файл расписания
- main.cpp - демонстрация работы
- CMakeLists.txt - сборка для Qt Creator / CMake
- Makefile - сборка для g++ в терминале

## Сборка:
```bash
make
./TimeProject
```
или
```bash
g++ -std=c++17 main.cpp Time.cpp Flight.cpp -o TimeProject
./TimeProject
```
